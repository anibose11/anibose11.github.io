How outreach priorities change which counties are selected

Animesh Bose, Norlowe Research

County planning study using CDC PLACES 2025 estimates and Census Bureau data, October 2026.

A program can prioritize places where diabetes is most common or places where the most affected adults live. This study compares those two choices with a poverty-based rule and measures how stable each resulting county list is within the published uncertainty.

Data sources and coverage

  • Prevalence: CDC PLACES County Data, 2025 release, "Diagnosed diabetes among adults", crude prevalence with 95% intervals. PLACES estimates come from a multilevel model of Behavioral Risk Factor Surveillance System (BRFSS) 2023 responses. They are estimates, not counts of diagnosed patients.
  • Adults: Census Bureau Vintage 2023 estimates of people aged 18 and older, as distributed with PLACES. The analysis code checked them against the Census Bureau file, and they matched exactly for all 2,956 counties.
  • Poverty: American Community Survey (ACS) 2020-2024 five-year estimates, with standard errors computed from the Census Bureau's 80 published replicate estimates.
  • Coverage: 2,956 counties in 48 states and the District of Columbia. Kentucky (120 counties) and Pennsylvania (67) have no diagnosed-diabetes estimates in the 2025 release because their BRFSS 2023 data did not meet the inclusion requirements.

Three definitions of need, set in the analysis plan

  1. Prevalence: the share of adults with diagnosed diabetes.
  2. Estimated burden: prevalence times the adult population, an estimate of how many adults have diagnosed diabetes.
  3. High-poverty prevalence: prevalence ranked only among counties where at least 20% of people are below the poverty level.

Each rule selects 10, 25 or 50 counties nationally and 5 within each state. The rules, capacities and uncertainty scenarios are set out in an analysis plan drafted with Claude Code under my direction. Its header gives a written time 13 minutes before the first ranked results were saved, but no hash of the plan was recorded that day and the saved file was created about 5 minutes after those results, so the written time rests on the header alone.

How the uncertainty bounds were used

Using published bounds without simulation. PLACES publishes one interval per county, and its estimates share a model, so their errors are not independent. Selection probabilities simulated from these intervals would depend on an assumed correlation between counties, which PLACES does not publish. The analysis used only interval bounds (the published PLACES limits and, for burden, scenario bounds built from them). A county is core if it stays in the top K when every county's value sits anywhere within its bounds, and boundary if it is in the top K for some of those values. The worst case is extreme by design, so these labels form a sensitivity envelope and carry no confidence level.

A matched adult denominator. Burden multiplies crude prevalence, not age-adjusted prevalence, by the adult population that PLACES itself used, and the code checks that population against the Census file. Because population estimates have no published sampling error, the burden bounds widen the denominator to cover the ACS 2020-2024 range as well and are labeled scenario bounds.

Which counties were selected, and how stable the lists were

  • At 25 counties, the prevalence and burden lists shared no county. Prevalence picked 26 small counties (a tie at the cutoff added one) in Alabama (7), Georgia (5), Mississippi (5), Louisiana (4), Texas (4) and Hawaii (1), with a median of 5,823 adults. Burden picked large metropolitan counties with a median of 1.82 million adults.
  • The high-poverty rule picked 25 of the same 26 counties as prevalence, because almost every highest-prevalence county is also high-poverty. PLACES uses poverty in its model, so this overlap is partly built in.
  • No prevalence-selected county was core at 25. The top-ranked county, Greene County, Alabama (27.1%, interval 23.9 to 30.2), could fall to rank 39.
  • The burden list was more stable: 17 of 25 counties were core.
  • Within states, prevalence and burden shared no county in 39 of 45 states.
  • National selections under all three rules at capacities 10, 25 and 50 were unchanged in a strictly aligned subset of 2,947 counties.
  • In the 2024 release, which includes Kentucky and Pennsylvania, those states held 0 of the top 25 places by prevalence and 1 by burden.

Limitations

The estimates are model-based and validated only moderately for diabetes at the county level, which suggests that true rankings carry more error than the published intervals show. The envelopes are not joint confidence sets. Only diagnosed diabetes is measured. The 20% poverty threshold is a declared planning choice. Kentucky and Pennsylvania have no diagnosed-diabetes estimates in this release. The shortlists say where to look. Acting on them needs local information on programs, capacity and community priorities that these data do not contain.

Reproduce the analysis

The reported run used Python 3.13.5 and R 4.5.1. The package needs Python 3.12 or later, and dop validate also needs R (base packages only). From the source archive:

python3 -m venv .venv && . .venv/bin/activate
pip install -r requirements.lock
pip install -e ".[test]"
pytest
dop acquire && dop build && dop analyze && dop validate && dop render

dop demo runs the same code on a small synthetic fixture in under a second, and scripts/run_all.sh runs every step in order. Every run is identified by a hash of the configuration, the analysis code and the source files. The run reported here is a944852459ca.
