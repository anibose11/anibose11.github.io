Metric definitions

Field Unit Definition
items count Eligible test prompts in the analysis population (unanimous accepted benchmark label, not on the corpus 'Incorrect' list).
parse_valid count Responses that parse as one JSON object matching the answer schema (code fences stripped; no other repair).
abstained count Parse-valid responses with label 'cannot determine'. Not the same as 'no significant difference'.
answered count Parse-valid responses that did not abstain.
quote_exists count Answered prompts whose quote, after collapsing whitespace, is a substring of one supplied passage and has at least 4 words.
quote_exists_strict count Answered prompts whose quote is an exact substring of the passages as displayed to the model, any length (sensitivity S1 adds the 4-word minimum).
locator_valid count Answered prompts whose returned passage ID names a supplied passage containing the quote.
gold_overlap count Answered prompts whose located quote overlaps an accepted benchmark evidence span by at least one character.
label_correct count Answered prompts whose label equals the benchmark label.
task_success count Answered, quote exists, locator valid, and label correct. Denominator: all items.
qvwr proportion Label-error rate among quote-valid answers: label_wrong / answered prompts with an existing quote.
ci_low, ci_high proportion 95% percentile interval from 10,000 bootstrap resamples of articles (seed 20261007).
coverage proportion Retained answers / items.
macro_f1 proportion Mean F1 over the three benchmark classes; abstentions and invalid outputs count as a wrong 'no answer'.
retained_error proportion Wrong labels / retained answers under a rejection policy.
random_* proportion Coverage-matched random rejection: 2,000 seeded draws keeping the same number of answered prompts.
